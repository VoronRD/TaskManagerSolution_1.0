# Task Manager

Настольное приложение-планировщик задач на C# и WPF.

Приложение предназначено для локального управления задачами пользователя: создания,
редактирования и удаления задач, установки сроков, назначения тегов, фильтрации,
поиска, работы с календарём и получения уведомлений о приближающихся дедлайнах.

## Возможности

- создание, редактирование и удаление задач;
- установка приоритета и статуса задачи;
- назначение цветных тегов;
- поиск, фильтрация и сортировка задач;
- календарное представление задач;
- поддержка повторяющихся задач;
- автоматическое создание следующих экземпляров повторяющихся задач;
- уведомления о приближающихся дедлайнах;
- настройка параметров уведомлений;
- локальное хранение данных в формате JSON;
- автономная работа без подключения к интернету.

## Технологии

- C#
- .NET
- WPF
- XAML
- MVVM
- Prism
- JSON

## Архитектура

Приложение построено на основе архитектуры MVVM и разделено
на независимые функциональные модули с использованием Prism.

Основные модули:

- `TaskManager.Core` — основные модели и перечисления предметной области;
- `TaskManager.Infrastructure` — работа с данными, уведомления,
  настройки и вспомогательная логика;
- `TaskManager.TasksModule` — создание, редактирование, поиск,
  фильтрация и сортировка задач;
- `TaskManager.TagsModule` — управление тегами;
- `TaskManager.Calendar` — календарное представление задач;
- `TaskManager.SettingsModule` — настройка уведомлений;
- `TaskManager.Shell` — основной модуль приложения и навигация.

## Хранение данных

Для локального хранения задач и тегов используется формат JSON.
Приложение не требует развёртывания базы данных или подключения
к внешнему серверу.
