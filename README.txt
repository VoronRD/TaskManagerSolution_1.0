\# Task Manager

Приложение для управления задачами, разработанное на C# и .NET.

## О проекте

Проект представляет собой приложение для создания и управления задачами.
Архитектура построена с разделением основных компонентов приложения на отдельные модули.

## Основные возможности

- создание и управление задачами;
- работа с тегами;
- работа с календарём;
- настройка параметров приложения;
- разделение бизнес-логики и инфраструктурного кода;
- модульная организация проекта.

## Архитектура

Проект разделён на несколько основных компонентов:

- `TaskManager.Core` — основная бизнес-логика и модели;
- `TaskManager.Infrastructure` — инфраструктурный слой;
- `TaskManager.TasksModule` — работа с задачами;
- `TaskManager.TagsModule` — работа с тегами;
- `TaskManager.Calendar` — функциональность календаря;
- `TaskManager.SettingsModule` — настройки приложения;
- `TaskManager.Shell` — основной пользовательский интерфейс.
